This is still IZUKI.
Only the light changed.

The starting point is the real floating panel, not a landing page. The same mark, the same “YO IZUKI, DO IT.”, the same Nova glass, the same command strip and the same Island. The proposal is a material and interaction pass: deeper light, clearer states, and motion that responds to you instead of performing at you.

No replaced navigation No new headline inside the app No change to Eye Control
Non-negotiables01—04
  • Keep the floating object. The panel stays a compact Windows surface, not a full-page app.
  • Keep the voice. Mark, tagline, copy and the direct command-strip language stay.
  • Keep the rhythm. Capsule tabs and the same tab order; only the active state gets more craft.
  • Keep it fast. One-shot transitions, static aurora, no permanent blur over live video.

03 / The boundary

What stays. What moves. What never changes.

Keep

  • The floating panel and its 32px silhouette.
  • The mark, wordmark and tagline.
  • Nova colours as the default atmosphere.
  • Capsule tabs and tab order.
  • The command strip under the tabs.
  • The Island as a tiny black pill.
  • AIR cyan rings, brackets and hand glyphs.

Lift

  • Top-edge specular and a soft inner bloom.
  • Active-tab lens with clearer contrast.
  • Focus light on the command strip.
  • Pointer-reactive panel light, no loop.
  • One-shot tab and panel entrances.
  • Island busy rim without growing it.
  • Calmer AIR hierarchy with the same parts.

Protect

  • Keyboard focus order and labels.
  • 44px targets and 200% zoom.
  • Reduced motion for every effect.
  • No idle loops over live video.
  • No blur on moving video or the overlay.
  • No Eye Control files touched.
  • No merge or release without functional verification.

This is an evolution study, not a replacement. The next implementation step should be a small material pass on the existing header, tabs and command strip, followed by a real before/after capture at the same window size. The older Monolith, Tidal and Field Notes board remains inspiration only.
