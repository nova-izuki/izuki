# Izuki 1.0.71: ask about this page, from the Island

## Ask about this page
With a web page in front, open the Island (rest the mouse at the top of the screen) and you'll see **Ask about "the page's name"**:
- Type any question, or tap **Sum this page up**, **What should I do here?** or **Explain it simply**.
- The answer types itself out in the Island, with **Copy** and **New question** when it's done.
- Follow-ups carry on the same conversation until you go to a different page.
- The Island stays open while you're asking or reading. Close it with ✕ or Esc.

With the Izuki browser extension, Izuki reads the page exactly as the browser shows it, plus the links on it most related to your question (a syllabus, assignment details), using your own sign-ins. It never reads links like Log out, Delete or Buy. Without the extension, it reads the page through Windows' accessibility view.

The same extension page reading already powers screen control: when the extension is on, Izuki clicks links and buttons inside web pages exactly, by the page's own elements, rather than guessing from a screenshot.
