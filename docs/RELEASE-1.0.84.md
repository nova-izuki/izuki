# Izuki 1.0.84: see where Izuki will click

## "Show where I'll click" (optional)
Settings → Control → **Show where I'll click**. With it on, a box appears on whatever Izuki is about to click or type into, half a second before it happens. It works in every mode, Jarvis mode included, where clicks used to happen with nothing on screen. Press Stop while the box is up and nothing is clicked.

It's off by default, so clicks stay as fast as before.
