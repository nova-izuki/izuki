# Izuki 1.0.55

Clearer command results in Chat, and a smarter TV.

## Command cards in Chat
- Every command shows how it really went:
  - Green ✓ when it worked.
  - Amber ⚠ when it finished but skipped a few things, like files that were in use.
  - Red ✕ only when it actually failed.
- When Izuki's proof check confirms the job is done (for example, temp files cleared), the card is green even if Windows returned a code because a few files were locked.
- Click a card's header to collapse or expand it.
- Hover to copy the command or the output, or copy everything at once.
- **Expand** opens the card full screen, with line wrap on or off and copy buttons. Press Esc to close.

## Smarter TV
- "What apps are on my TV?" lists them, out loud and on the TV.
- "Show me free movie apps" shows which of your apps are free to watch, and which need a subscription.
- "Is Netflix free?" answers, and suggests free apps you already have.
- "Open YouTube on the TV and search for MrBeast" (or "search YouTube for lofi music on the TV") goes straight into that app.
- On the TV page with Hey Nova off, the orb settles back a few seconds after it answers, and springs forward when you hold OK.
