# Izuki 1.0.43

Izuki stops opening and tapping things you didn't ask for — it asks when it's unsure, closes its own detours, and no longer mistakes your words for your name.

## Fewer wrong taps
- **Asks instead of guessing.** When a spoken request doesn't make sense (speech recognition heard "open methods only, open networks"), Izuki now asks one quick "Did you mean …?" instead of opening something random. Clear but oddly worded requests ("open you tube") still just work.
- **Closes its own detours.** If a step brings up an app the task never asked for — Settings popping up while it looks for the Recycle Bin — Izuki notices, closes it and carries on, instead of working around it.
- **Stays on the task.** It only opens, clicks and types what the request needs.

## It gets your name right
Commands like "go back" and "check again" were sometimes saved as your name ("call the user Back", "Again"). Those are cleared out automatically, and it can't happen again — tell Izuki "my name is …" any time.
