# Izuki 1.0.31

Jarvis mode: Izuki works without touching your mouse.

## Jarvis mode (no mouse)

- **Settings → Execution → Control style → Jarvis mode — no mouse** (or tap
  the mode name at the top of the Chat tab to switch). Izuki presses buttons
  **and now types into boxes** directly through Windows: no hand flying
  across the screen, faster, and your own mouse stays free while it works.
  If a box won't take text that way, it falls back to clicking and typing.
  Password boxes are never touched.
- Mouse mode is still there for games and drawing apps, where a real
  pointer is needed.

## Understands chat shorthand

- "wats the ans", "pls open yt", "nxt song", "turn it up rn" — read as plain
  words, so the instant commands (no AI) get them too.
