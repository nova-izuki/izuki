# Izuki 1.0.78: waveforms, smarter Island, lessons that start themselves, notes menu

## The Island
- **Pick your waveform:** Settings → Talk to Izuki → **Island waveform**: Silk, Bars, Mirror, Neon or Dots, or **Auto**, which gives every song its own look.
- **It knows what's playing.** Songs get "About this song" and "Flow with it". Lessons ("how to…", tutorials, lectures) get "Explain this lesson". Ads get "Skip ad". Other videos get "What's this video about?".
- **No more text running out of the box** in "Happening now": long details wrap underneath. The open Island also scrolls when it holds more than fits.

## Teach in real time
Type a topic and press **Teach in real time** (or Explain now). If nothing's playing, Izuki finds a good video for it, opens it in the Izuki browser, makes sure it's really playing, then teaches as it goes. Before, it opened YouTube and stopped there.

## Notes
- Every note has a **⋯ menu**: Open, Summarise, Quiz me, Copy text, Select, Delete.
- **Select** several notes to delete, summarise or copy them at once. If a delete fails, Izuki says so and keeps those notes selected to try again.

## Jump bar everywhere
Notes, Flows and Watchers now have the jump bar too, and on every page it follows you as you scroll down.

## PC Boost
- **Recycle Bin:** see how full it is and **Empty it** (Izuki shows the current size and asks first). New **Clear old Recycle Bin items** (off until you turn it on) deletes only what has sat in the bin for 30+ days, so you always have a month to change your mind.
- **"Clear duplicate downloads"** and **"Clear old Recycle Bin items"** now each work on their own. Before, they quietly needed "Keep my PC fast 24/7" on too.

## Updates
Izuki now checks for updates every hour (not every six) and tells you on the Island when a new version is out.
