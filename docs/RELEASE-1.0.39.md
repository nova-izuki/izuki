# Izuki 1.0.39

The Izuki browser extension: web pages seen exactly, clicks that never miss.

## Izuki for Chrome and Edge

- A free **browser extension** that lets Izuki see a web page the way the
  page itself does — every real link and button, its name, and where a link
  goes — instead of guessing from a screenshot. Clicks land on the exact
  element, on any site.
- In **Jarvis mode**, Izuki clicks and types **right inside the page** — no
  mouse at all, and it works even when the button is half off-screen.
- Private: the extension only talks to Izuki on your own PC (127.0.0.1),
  and only when Izuki asks. Web pages can't use the connection.
- Add it in a minute: **Settings → Browser extension** (download, unzip,
  Load unpacked in chrome://extensions). The card turns green when it's
  connected.
- Tested end to end: the extension listed a quiz page's answers, box, Next
  button and link exactly, typed into the box, and clicked Next.
