Your AI, beside the page.

Add Izuki to Chrome, Edge or a compatible Chromium browser. The browser confirms when an extension is added.

The easiest setup from Izuki

  1. Update the Windows app, then open Settings → Browser extension.
  2. Choose your browser and click Set up in this browser. Izuki unpacks its files and opens the right extension page.
  3. Turn on Developer mode, click Load unpacked, and paste the folder location Izuki gives you.

When it connects, Izuki shows connected. Pin its icon to open the chat panel next to your pages.

Get the Windows app
Download the extension yourself

Download extension ZIP

  1. Extract the ZIP.
  2. Open your browser's extension page. Choose below to copy its address.
  3. Enable Developer mode, click Load unpacked, and choose the extracted izuki-extension folder.

chrome://extensions/

Store installation

A direct Add extension store listing has not been published yet. Until then, the setup above is available. Once published, store installations can receive browser-managed updates.

This package uses Chromium extension APIs. Firefox and Safari need separate builds. Alternate Chromium browsers can differ in side-panel support.
