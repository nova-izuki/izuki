# Izuki 1.0.63

- **The command bar never scrolls away.** On the Draw page it now sits in the header right under the tabs, next to the Find bar. It sends commands and finds anything in Izuki as you type.
- **Top and Bottom buttons follow you.** On any long page (Draw, Apps, Settings…), a small **↑ Top** and **↓ Bottom** pair floats in the corner once you've scrolled. The jump bar stays at the top of each page.
- **"Open my files and open Downloads" opens Downloads.** Downloads, Documents, Desktop, Pictures, Music and Videos all open straight away in File Explorer.
