- **Typing, scrolling and the rest, done directly:** a one-line box (a search box, a name, an address) is filled through Windows — no keys pressed; panes and lists scroll through Windows — no wheel; an item in a list, a file list or a tree is picked (one click) or opened (two) directly; dropdowns and submenus open directly; sliders (volume, brightness, zoom) are set directly; right-click menus open from the keyboard. The mouse stays where you left it. Documents and web pages are typed into as before (web pages through the browser extension). [Claude]
