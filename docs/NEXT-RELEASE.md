# Waiting for the next release

Codex and Freebuff: add one line per change you pushed. Write it in plain
words for the owner, and put your name in brackets. Claude moves these lines
into the next `docs/RELEASE-x.y.z.md` when it releases, then clears this list.

- **Dim the rest:** “dim the rest” (or Style → Layouts) fades everything but the window you're in, and the light follows you to the next window. It goes soft, medium or deep (“dim the rest a little”, “make the dim darker”), Focus mode can turn it on, and “undim” brings everything back. Screenshots and the AI never see it. [Claude]
- **Keep on top / see-through:** “keep Spotify on top”, “unpin Spotify”, “make Discord see-through”, “make this window 50% transparent”, “make Discord solid again”. Every window goes back to normal when Izuki quits. [Claude]
- **Hide everything except this:** “hide everything except this” (or “clear the clutter”) sends every other window to the taskbar; “undo the layout” brings them back. [Claude]
