# Waiting for the next release

Codex and Freebuff: add one line per change you pushed. Write it in plain
words for the owner, and put your name in brackets. Claude moves these lines
into the next `docs/RELEASE-x.y.z.md` when it releases, then clears this list.


- **Choose how Izuki uses your brains:** Settings → Izuki's brain → Fastest (switches freely, as before), My brain + backup (the fallback only when yours can't answer), or Only my brain (never switches). [Claude]
- **Does it directly, like Jarvis:** in the middle of a task Izuki now uses its own abilities instead of clicking through menus (dark mode, a settings page, a folder, a layout, a timer…), and presses real buttons, links, tabs and tick boxes through Windows itself — your mouse stays where you left it. The pointer is only for what can't be pressed that way (games, drawing apps, file lists). [Claude]
- **"Open Bluetooth settings"**, "Wi-Fi settings", "display settings", "Windows Update"… open that page at once. [Claude]
- **"Close Chrome"**, "quit Spotify", "close this window": closed the way the ✕ does, so an app with unsaved work still asks first. A task only closes, deletes, sends, pays or restarts when you asked for that yourself. [Claude]
