# Waiting for the next release

Codex and Freebuff: add one line per change you pushed. Write it in plain
words for the owner, and put your name in brackets. Claude moves these lines
into the next `docs/RELEASE-x.y.z.md` when it releases, then clears this list.
- The terminal windows that flashed open and shut are gone: the repo sync was started by the task scheduler as a PowerShell window every ten minutes, and Windows shows a console for a moment each time. It now starts through a tiny windowless launcher, so the sync still happens but nothing appears on screen. A PC that still has the old task gets it replaced by running the install line in tools/two-machine/README.md once. [Freebuff]
- In the headset, the name you call Izuki by is worked out once instead of on every sentence, and a name that is just an ordinary word ("okay", "so", "now", "hey") is refused instead of quietly making every sentence a call. A name that is also a person's name ("Leo", "Nia") now needs "Hey Leo" or "Leo, …", so "Leo is coming over" no longer wakes Izuki. [Freebuff]
- Notes has a Study coach now: type what you are studying (or tap one you did before) and it explains it in a few steps, says it again more simply when it does not land, shows a worked example, then quizzes you one question at a time. It keeps the topic and how far you got until you change it, and answers show in Chat. [Freebuff]
- The version bump is one command now (`tools/bump-version.mjs`): it writes every file `docs/BUMP-CHECKLIST.md` names, phone build numbers included, turns the pending lines into that release’s notes, and fails rather than skipping a row. [Freebuff]
- The iPhone build retries the Capacitor package clone, so a network blip no longer leaves a release a draft with no IPA. [Freebuff]
- The floating orb no longer stays over your other apps after Izuki's work is done: with “Keep a small orb over other apps” off (the default) it leaves with the work instead of resting there until you hide it. [Freebuff]
- The orb and the glow around the screen stopped doing six times the work on every frame, so the phone stays smoother while Izuki talks and listens over another app. [Freebuff]
- Izuki can't talk over itself on the phone any more: a new line stops the one already playing instead of both going at once. [Freebuff]
- When Android's speech service was busy for a second, the phone gave up on its own ears for the rest of the session and asked for a key instead; it now waits and tries again, and a new call always tries them again. [Freebuff]
- "Hey Nova" no longer answers with silence and a "Listening…" orb when the phone's voice takes a few seconds to start: it waits for the "Yes?" it is about to say. [Freebuff]
- Diagnostics has a Voice line and the last ten voice events, so a wrong voice or an ear that heard nothing can be read off the phone. [Freebuff]
- Every turn now leaves a timeline in Diagnostics — the tap or wake word, the first words heard, the transcript, the first word of the answer, the first and last sound, and which voice spoke, each counted in seconds from the start — so “it’s slow” reads as numbers. [Freebuff]
- A bare “Hey Nova” now opens the ear while it says “Yes?”, so answering at once is heard instead of talked over and then asked to repeat: its own greeting coming back through the microphone is recognised and ignored, and the greeting stops the moment real words arrive. [Freebuff]
- Typing the next message while an answer is still coming out now sends it, instead of stopping the answer: the send button was Stop whenever Izuki was working, so a message sent mid-answer killed the reply, dropped the words and said it had been stopped. [Freebuff]
- Drive mode stops chiming: a quiet microphone used to be reopened every quarter of a second (Android plays its sound on every open and close), and Izuki's own spoken line coming back through the speaker was asked as a new question, which kept the loop going. It now waits longer after each quiet try, restarts less, and ignores its own words. [Freebuff]
- The Izuki browser now works where you can see it: when Izuki opens a page or clicks and types for you, that window comes up with the page instead of staying hidden, so you can follow the steps and take over. [Freebuff]
- The browser side panel can now work the page you are actually on: with “Let Izuki use this page” on, it numbers that tab’s buttons, links and fields, presses one and types into one, and looks again after each step, so it works on the site you are signed in to instead of only in a window of its own. Passwords are never read or typed, and a press that sends, buys or deletes is left for you. [Freebuff]
- Typing into a message box with Enter no longer sends it behind the guard: boxes whose Enter sends (a message, a reply, a comment, or a box beside a Send button) are marked when the page is numbered, and that Enter is left to you. [Freebuff]
- The side panel can type into chat boxes now: Slack, WhatsApp Web, Gmail’s compose and the other editable boxes that are not form fields are numbered and typed into like fields, with the same rule that Enter in a box that sends is left to you. [Freebuff]
- Izuki keeps going on the page now: after each step it reads the page again and carries on, up to twelve steps instead of four, and it says so when it reaches the limit. Chat boxes send on Enter by default, so that Enter is left to you; a long-form box like Gmail’s body keeps it, because there Enter is a new line. [Freebuff]
The side panel no longer loses a task when something else gets to it first: the next round of a page task waits for the panel instead of being dropped, and says so if it had to stand back. Before, typing a question in that moment ended the task with no explanation. [Freebuff]
A step the page does not take now ends the task: an item that was renumbered away, or a press the page refused, stops it with "That's where it stopped — nothing on the page changed" instead of asking for the same step again. [Freebuff]
There is a page in the repo to try the panel's clicks and typing on without any real site: tools/fixtures/page-actions.html has a message box with a Send button, a long-form body where Enter is a new line, a three-step form, a password box and a button that removes itself, and logs what it saw. [Freebuff]
The extension the website hands out now has today's side panel and page actions in it: the download was packed before the panel could click and type on your page, so a fresh install had none of it. [Freebuff]
The build's own dependencies are on versions with no published advisories: npm audit reported eight (vite, sharp, glob, minimatch, rimraf, source-map-js) and now reports none. [Freebuff]
A version bump moves package-lock.json too, so a release can no longer leave the lockfile behind (it had drifted to 1.0.224 while the app was at 1.0.226, which would have rewritten the lock inside a release commit). [Freebuff]
The developer build's own tests are warning-free now: the owner-only Smart Vision code carried four warnings (two unused imports, a note limit and a boot flag nothing read, and a disarming call whose result was dropped), and `tools/test-windows.ps1` compiled all four of them every run. Public builds never contained that code. [Freebuff]
- An everyday phrase like “so now” or “hey there” is refused as the phone's wake phrase, because Izuki would have woken on ordinary speech all day; the note says why, a phrase with a real name in it still works, and a phrase already saved that is all everyday words simply stops waking. [Freebuff]
- When Android switches Izuki's control off because the app was updated, Izuki now says that instead of just “off”, and the button on that row opens the switch itself. [Freebuff]
- “Hey Nova” stays off once you turn it off: a restart of the app used to switch it back on by itself, which is why the microphone chimed open and shut on its own. [Freebuff]
- After “Hey Nova” and its “Yes?” hears nothing, the phone now tries once more instead of three times, two seconds apart, so it stops clapping its microphone open and shut while you decide what to say. [Freebuff]
- Diagnostics now says whether “Hey Nova” answers where you are or opens Izuki, and which of the four things it needs was missing, and a “Hey Nova” that arrives while Izuki is still talking is kept instead of thrown away. [Freebuff]
- Answering “I’m here.” with “yes” now means “go on”, so the phone stops answering its own greeting and listens for what you actually want. [Freebuff]
- Android control being off after a reinstall now says so plainly instead of a bare “Off”, and the turn’s ear waits two seconds for you to start instead of one. [Freebuff]
